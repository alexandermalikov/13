# 13-maktab

Адаптивный одностраничный сайт школы № 13 на Vue 3 и Vite.

## Запуск

```sh
npm install
npm run dev
```

Для production-сборки используйте `npm run build`, для локального просмотра сборки — `npm run preview`.

## Возможности

- Узбекский интерфейс по умолчанию и переключение на русский.
- Светлая и ночная темы; выбор темы сохраняется в браузере.
- Адаптивная навигация, фильтр новостей и анимации с поддержкой `prefers-reduced-motion`.
- У каждой новости отдельная страница и ссылка вида `/13/#/news/slug`; маршрутизация работает на статическом размещении проекта.
- Новости, команда и информация о школе читаются из Supabase. До подключения переменных окружения приложение использует демонстрационные новости и локальное хранилище браузера для изменений.
- Панель редактора доступна по адресу `/#/admin`: новости можно создавать, публиковать, менять и удалять; там же редактируются учителя, ученики и тексты о школе.
- Панель администратора переключается между русским и узбекским; фото новости загружается в Supabase Storage и отображается на главной и странице публикации. Дата публикации выставляется автоматически.
- Фото школы используется как фоновое изображение первого экрана. Кадрирование, цвет и контраст настроены в CSS; исходный файл не изменён.

## Структура

- `src/App.vue` — текст сайта, переключатели и секции главной страницы.
- `src/components/Header.vue` — навигация, выбор языка и темы.
- `src/pages/HomePage.vue` — главная страница и карточки новостей.
- `src/pages/NewsDetail.vue` — общий шаблон отдельной публикации.
- `src/data/news.js` — демонстрационные начальные новости на двух языках.
- `src/services/contentService.js` — Supabase REST/Auth и локальный демонстрационный режим.
- `src/pages/Admin.vue` — панель управления.
- `src/pages/DeveloperAdmin.vue` — отдельная панель создания администраторов.
- `supabase/schema.sql` — схема таблиц, индексы, гранты и RLS-политики для Supabase SQL Editor.
- `supabase/news-images.sql` — bucket обложек с ролевой политикой загрузки.
- `supabase/functions/create-admin/index.ts` — серверная Supabase Edge Function для безопасного создания учётных записей.
- `supabase/bootstrap-developer.sql` — одноразовое назначение роли первой учётной записи разработчика.
- `src/main.js` — маршруты Vue Router.
- `src/style.css` — палитра, адаптивная сетка, фон и анимации.
- `src/assets/back-image.png` — фотография школы.

## Подключение Supabase

1. Скопируйте `.env.example` в `.env.local` и заполните Project URL и anon/publishable key из настроек проекта Supabase.
2. В Supabase откройте SQL Editor, вставьте содержимое `supabase/schema.sql` и выполните его.
3. Для загрузки фото новостей отдельно выполните `supabase/news-images.sql` в SQL Editor. Он создаст публичный bucket `school-news` с ограничением 5 МБ и разрешит загрузку только администратору или разработчику.
4. Создайте первую учётную запись разработчика в **Authentication → Users**, затем в SQL Editor замените `YOUR_EMAIL_HERE` в `supabase/bootstrap-developer.sql` и выполните запрос.
5. В Supabase откройте **Edge Functions → Deploy a new function → Via Editor**, назовите функцию `create-admin` и вставьте код из `supabase/functions/create-admin/index.ts`. Нажмите **Deploy function**. Edge Function использует серверные переменные Supabase; service-role ключ остаётся только на сервере.
6. Войдите как разработчик на `/#/developer`. Из этой отдельной панели создавайте администраторов по email и паролю. Администраторы входят через `/#/admin`.
7. Перезапустите Vite после изменения `.env.local`.

Таблицы: `school_news` (переводы в JSONB), `school_people` (учителя/ученики и переводы), `school_settings` (ключ/значение для текста об организации). Политики разрешают публичное чтение сайта, а CRUD — только аккаунтам с `app_metadata.role` равным `admin` или `developer`. Не помещайте service-role key в клиентское приложение. Сначала содержимое создаётся через панель; демонстрационные новости автоматически в Supabase не копируются.
